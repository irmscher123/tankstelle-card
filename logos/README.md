# Logos

**DE:** PNG-Logos der Tankstellen. Die Dateinamen müssen zu `BRANDS` in `tankstelle-card.js` passen. Am besten quadratisch, ca. 96×96 px, transparent oder mit eigenem Hintergrund.

**EN:** PNG logos of the petrol stations. File names must match `BRANDS` in `tankstelle-card.js`. Ideally square, about 96×96 px, transparent or with their own background.
